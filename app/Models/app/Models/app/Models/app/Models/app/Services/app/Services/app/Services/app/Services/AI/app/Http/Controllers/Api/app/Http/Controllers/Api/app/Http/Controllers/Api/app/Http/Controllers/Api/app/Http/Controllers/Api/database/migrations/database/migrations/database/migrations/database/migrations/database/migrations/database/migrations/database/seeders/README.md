# 🏢 Al-Ashari ERP System

نظام ERP محاسبي ذكي مبني على Laravel 11

## ✨ الميزات
- 🛒 نظام مبيعات (POS)
- 📦 إدارة المخزون
- 📊 محاسبة قيد مزدوج
- 🏢 تعدد الشركات
- 🤖 ذكاء اصطناعي
- 🔐 مصادقة آمنة

## 🚀 التثبيت

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```
